# Gamedistribution SDK Extension

[Website/Releases](http://www.polydes.com/repo/engine/com.gamedistribution) |
[Issues](https://github.com/polydes/gamedistribution/issues)

</div>

This [Stencyl](https://www.stencyl.com/) extension provides integration with the Gamedistribution [HTML5 SDK](https://gamedistribution.com/sdk/html5) for games intended for upload to the [gamedistribution.com](https://gamedistribution.com/) game portal.

## Using this Stencyl extension

This is a free extension. Installation instructions and guides can be found [here](http://www.polydes.com/repo/engine/com.gamedistribution/).
