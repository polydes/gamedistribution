This extension provides integration with the Gamedistribution [HTML5 SDK](https://gamedistribution.com/sdk/html5) for games intended for upload to the [gamedistribution.com](https://gamedistribution.com/) game portal.

Most features of the HTML5 SDK are supported, including:
- ✔ Showing video ads
- ✔ SDK events
- ✔ IMA SDK events
- ✔ Ad events
